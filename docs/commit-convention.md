# Commit Convention

## 커밋 메시지 형식

```
[Type/#이슈번호] - 제목

본문 (선택)
```

### 예시

```
[Feat/#1] - 로그인 함수 추가

로그인 요청을 위한 함수 구현
```

---

## Commit Type

타입의 첫 문자는 **대문자**로 작성한다.

| 타입 | 설명 |
|---|---|
| `Feat` | 기능 추가/수정 |
| `Fix` | 버그 수정 |
| `Docs` | 문서 수정 |
| `Style` | 코드 포맷, 스타일 수정 |
| `Refactor` | 코드 리팩토링 |
| `Test` | 테스트 코드 추가 |
| `Chore` | 기타 작업 (빌드 설정 변경 등) |

---

## 제목 (Subject)

- `[Type/#이슈번호] - 제목` 형태
- 최대 **50자** 이내
- 마침표 및 특수기호 사용 금지
- 간결하고 요점적으로 서술

## 본문 (Body)

- 선택 사항
- **어떻게**보다 **무엇을, 왜** 변경했는지 작성
